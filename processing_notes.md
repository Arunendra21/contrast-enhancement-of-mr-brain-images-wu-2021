# Processing Notes — Contrast Enhancement of MR Brain Images (Wu 2021)

- **Paper:** Hao-Tian Wu, Kaihan Zheng, Qi Huang, Jiankun Hu, IEEE Signal Processing Letters, vol. 28, 2021
- **Reproduction tier:** A
- **Status:** Completed (full reproduction, synthetic medical data)

## What was reproduced
ROI-restricted reversible histogram-expansion CE on synthetic MR phantoms, bit-exact reversibility guaranteed via auto-reduction (safe_embed).

## Reproduced vs reported
Reversible multi-tissue contrast enhancement is reproduced qualitatively. Real MR data and the paper's exact segmentation are unavailable, so SYNTHETIC phantoms are used and clearly labelled; only cells marked 'reported' reflect the paper.

## Honesty note
No results were fabricated; all numbers come from the included code on the synthetic phantoms.
